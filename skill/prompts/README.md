# MyRag 提示词配置目录

每套提示词一个 `.md` 文件，入库/概括时按内容类型选用（Agent 判型，用户可点名指定）。

## 文件命名与用途

| 文件 | 用途 | 适用 |
|---|---|---|
| `spoken-extract.md` | 口播视频干货提取（默认套） | sph 视频转录条目 |
| `article-extract.md` | 文章 summary/tags/concepts 的补充概括 | 需要长文精炼版时 |
| `idea-extract.md` | 观点/趋势类提炼 | 理念类条目 |

## 使用约定

1. 概括结果只进两条通道：① 入库时的 `summary`（≤60 字，硬约束不变）；② 对话里给用户的「干货笔记」（不受 60 字限制）。
2. 提示词只作用于概括产物，**不改动 stage 原文与正式存储的 raw 正文**。
3. 新增一套 = 新增一个 md 文件，不改后端代码。
4. 视频转录条目默认套 `spoken-extract.md`；用户点名某套时以用户为准。
