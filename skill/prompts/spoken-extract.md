# 口播视频干货提取（spoken-extract）

输入：视频号口播逐字稿（已做 ASR 专名修正）。
输出两段：A) 入库 summary；B) 干货笔记。

## A. 入库 summary（硬约束 ≤60 字）
一句话说清视频讲了什么，含核心主张。不写"作者认为"套话。

## B. 干货笔记（给用户，结构如下）

```
## 干货笔记：<标题>
> 来源：视频转录 @ <账号名> | 时长 <mm:ss>

### 核心主张
1-3 条，每条一句硬话，不带口播水词。

### 关键机制 / 方法（如有）
视频里实际给出的结构、步骤、对比维度。没有就写"无"，不硬凑。

### 可信度备注
- 是否为观点性口播（无数据/实现支撑）
- ASR 专名修正之外仍存疑的表述
- 广告/引流内容（如有，单独标出，不计入干货）

### 与库内条目的关联（如可判断）
一句话说明与已入库哪几条同主题、互相印证还是冲突。
```

## 纪律
- 只提取"他说了什么"，不改写成"应该是什么"。
- 视频里的数字、断言原样保留，不替它背书。
- 广告、求关注、导流语句一律不入干货。
